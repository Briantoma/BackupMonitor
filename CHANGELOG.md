# Changelog

## 1.0 - 2026-11-09

First public release, as Backup Monitor (previously Silverstack Island).

- Slow copy warning per source card, with camera letters and minimum speeds for camera cards, audio cards and other sources.
- Settings window: island and menu bar icon on or off, menu bar readouts, card groups, notifications, Open at Login, version.
- Menu bar readouts: percentage, time remaining, number of jobs, progress wheel.
- Notifications for slow copies (on by default), jobs finished, failed or stopped, and unreadable logs.
- Warning when Silverstack is running but its log can't be read.
- Universal build for Apple Silicon and Intel Macs.
- Update check against GitHub releases, About window.
